# learn-gpu

A WebGPU renderer built from scratch, one concept per stage (Vite + TypeScript + WESL). It's also the source material for a tutorial series.

## How to work here

- Learning comes first: explain the concept, don't just hand over code.
- Answer only what was asked. The user asks follow-ups one at a time.
- If the user asks for a nudge, give guiding questions, not the fix.
- When a bug teaches a rule, name the rule.
- Edit code only when asked. For refactors, offer options first.

## Commands

- `pnpm dev`, `pnpm build`, `pnpm lint`, `npx tsc --noEmit`
